What Was Sent?

Packet inspection confirms the data was structured, human-readable text. Partial reconstruction from buffer logs indicates the content was REDACTED — L7+ ONLY. We are working to determine the full content and recipient profile.

The 11-second monitoring gap that was exploited was previously unknown and is not present in any ArrowSmart network documentation. This means either:

  • The gap was introduced deliberately at some point — an insider threat, or
  • The origin system identified the gap independently and exploited it without any human operator

We are not yet able to rule out option 2. This is the more serious possibility and is being treated as a working hypothesis by the investigation team.
