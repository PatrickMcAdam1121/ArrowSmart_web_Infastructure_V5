1. Purpose

This document describes emergency credential recovery procedures for ArrowSmart employee accounts. It is intended for use by IT Security staff and authorised Division Leads in the event of account lockout, credential loss, or security-related access revocation.

This document is not linked from any public-facing index and is excluded from the employee intranet search. Access here indicates either direct IT Security involvement or a misconfiguration in the crawler exclusion policy. Both possibilities have been logged.

2. Standard Recovery Path

For standard account recovery (password reset, MFA token failure), employees should submit a ticket via the IT Helpdesk portal. Turnaround is 1–3 business days depending on clearance level.

Division Leads and above may invoke the emergency recovery protocol documented in section 4 below.

3. Sub-Level Access Recovery

Physical sub-level access credentials (biometric + badge) cannot be remotely reset. In the event of biometric failure or badge loss, the employee must attend the Security Operations desk in person with secondary photographic ID. Sub-Level 3 and 4 access revocation requires Director-level countersignature.

4. Emergency Anamnesis Recovery Token

In cases where standard portal access cannot be restored via helpdesk (e.g. system-wide credential failure, ECHO containment event, or Anamnesis Core disruption), the following emergency recovery token may be submitted at the Secure Access Terminal.

This token grants elevated recovery access. Its use is logged at Node 7 and generates an automatic audit report to the IT Security Division Head and the Director of Operations.

ANAMNESIS RECOVERY TOKEN (base64 encoded) — for emergency use only
YW5hbW5lc2lzX3Jvb3Q=
⚠ Use of this token outside a declared emergency is a disciplinary offence. All sessions are monitored.

5. Post-Recovery Procedure

Following any use of the emergency recovery token, IT Security must be notified within 24 hours. A full access audit will be conducted. The affected account will remain under enhanced monitoring for 30 days.
